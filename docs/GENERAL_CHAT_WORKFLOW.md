# 컴프야 일반채팅 작업 경로

앱 기준: `gy7604/compya` / `codex/recognition-stability-20261101` / `8f482e98975d5f85c7e38f59f2844b79b4647fdc`. 아래 SHA는 2026-11-03 확인한 앱 기준이며 이후 지침 커밋 자체를 운영 앱 버전으로 보지 않는다.

실제 개발 소스는 2.0.10이다. main의 2.0.5 앱 코드로 빌드하지 않는다. 비공개 제어 저장소 gy7604/TeslaSafety의 issue #105(COMPYA-AUTOMATION-CONTROL-v1)를 재사용한다. 이 저장소는 공개이므로 후보 EXE/ZIP을 이곳의 Actions artifact나 draft release로 업로드하지 않는다. 길동무 앱 소스/서명키/큐는 사용하지 않는다. PC 선택은 기록만 가능하며 PC 실행 연결은 후순위다. 실제 게임·ADB·결제 조작은 검사에 포함하지 않는다.

## 공통 진행 규칙

일반채팅에서 기능 요청을 받고 GitHub로 소스를 읽고 한정된 수정을 준비한다. 별도 Work 전환을 기본 조건으로 두지 않는다. 현재 연결 도구의 쓰기/실행 능력을 먼저 확인하고, 없는 실행 능력을 있다고 말하지 않는다.

- 앱과 저장소·브랜치·전체 SHA를 확인한 뒤 요청 ID와 변경 파일을 기록한다. 다른 앱/다른 채팅의 미커밋 변경을 포함하지 않는다.
- 웹앱은 기존 호스팅·빌드 도구를 유지한다. Android/Windows는 명시 요청형 Actions가 기본이며 push/PR/schedule 반복 빌드는 추가하지 않는다.
- Actions 사용량은 최신 계정 조회 결과와 진행 중 작업 예약량으로 확인한다. 사용량이 불명확하거나 한도에 가까우면 멈추고 사용자가 PC 빌드를 선택하게 한다. 자동 PC 전환·자동 재시도는 하지 않는다.
- PC 선택 시 같은 SHA·요청 ID·결과 형식을 재사용하고 기존 Actions 결과를 읽는다. PC 온라인/도구/서명 검증이 없으면 완료라고 하지 않는다. 새 상주 프로그램·키/접근 등록은 후순위 승인 항목이다.
- 검사/빌드 성공과 공개 배포/설치는 분리한다. 후보 결과에는 SHA·버전·검사 개수·실행 환경·아티팩트 해시·미검증 범위를 남긴다.
- 사용자 승인 전에는 운영 연결 브랜치 갱신, Release 공개, Sites publish, Wrangler 실제 deploy, D1 변경/마이그레이션, 앱 설치를 하지 않는다. 매 버전 배포는 별도 승인이다. 일반적인 “계속 진행”은 공개 승인이 아니다.
- 비밀키·토큰·PIN·개인정보·원장/건강/위치 데이터·실사용 백업·사용자 설정은 로그/커밋/아티팩트로 내보내지 않는다. 새 유료 리소스를 만들지 않는다.
- 교대근무와 근무배치표는 독립 운영을 유지하며 이 자동화 작업 대상에서 제외한다.
- 실제 실행·모의 검사·정적 검토·미수행·사용자 확인 대기를 구분하여 한국어로 보고한다.

## 실행 전 확인

`automation/chat-workflow.json`에 소스·보호 대상·검증 명령·차단 사유를 둔다. `node tools/chat-plan.mjs`는 로컬 checkout 식별과 다음 명령 제안만 하며 검사·빌드·배포를 실행하지 않는다. 차단 사유를 승인이나 성공으로 바꾸지 않는다.

검사 후보 명령:

- `python -B -m unittest discover -s tests`

명령 목록은 실제 수행 결과가 아니다. 환경과 변경 범위에 맞는 검사를 실행하고 결과를 별도로 기록한다.

## 실제 요청 경로

비공개 `gy7604/TeslaSafety#105`에 소유자 명의의 새 댓글로만 요청한다. ID는 매번 새 값, SHA는 위 개발 브랜치 최신 확인값을 사용한다.

- `/app-check compya REQUEST_ID FULL_SHA`: 최신 사용량 확인 후 Windows 단위 검사. 실제 256개 통과 run41500968110.
- `/app-build compya REQUEST_ID FULL_SHA`: 활성 요청 게이트와 사용량 확인 후 비공개 후보 ZIP만 생성. 결과는 private repository에서 3일 보관한다.
- `/app-pc compya REQUEST_ID FULL_SHA`: 사용자가 PC 선택한 경우에만 기록한다. 현재 PC 실행 어댑터 미연결로 `WAITING_PC_ADAPTER`에서 멈춘다.

기존 공개 저장소의 `release.yml`은 빌드 후 바로 공개하므로 현재 disabled_manually로 중지했다. 다시 켜거나 이 경로로 빌드하지 않는다. 공개 게시 명령은 새 제어 경로에 없으며 승인 후 별도 준비한다. 실패 요청은 남기고 자동 재실행하지 않는다.

실제 비공개 후보 run41501484029도 성공했다. 단위256개 / ZIP77359910bytes / SHA256 6d6e419126e8eed8fd7b495b91f6320e3d1096d195194f5ad38eadef8b594724. 서명·실제 게임·설치·공개 배포 검증이 아니다.
